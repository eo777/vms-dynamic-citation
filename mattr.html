Reading the replay

The curves. The scoring window holds the last 50, 100 or 200 tokens. Its distinct-spelling count divided by its size is a single window's diversity. Each bold MATTR curve averages the latest 200 complete window scores. The thin line beneath each curve is the individual window scores; “Fine detail” hides or shows it. The pale band behind each Original Timm mean is that bifolium’s range over ten seeds of Timm’s program under the same geometry (seed 1 is the replay); “Means” hides the means and the bands. History continues across page and bifolium boundaries.

Actual manuscript. Observed words come from the same paragraph-text transcription and physical page order as the geometry audit. Model and observed token counts differ: the graph aligns physical lines and fractional progress within a line. This is a layout comparison, not a word correspondence. The horizontal axis counts manuscript tokens; the replay slider counts generated tokens.

Aligned plots. The manuscript is above Original Timm. Both panels share the same horizontal alignment and MATTR scale on the left. Each panel shows its own text's curve.

Bifolium means. Both plots contain the same horizontal blue and ink bands: the exact MATTR of each bifolium, averaging only complete scoring windows wholly inside it. Each has a solid center line and end caps: blue for Timm, ink for the manuscript. The current bifolium's values appear below the graph.

Sharp declines. Amber marks below each plot indicate a loss of at least 0.05 over 100 of that text's own tokens in its MATTR curve. Overlapping intervals are merged. The rule is identical for both texts. This is a descriptive threshold, not a significance test or causal attribution. Jump buttons move to the start of the next interval and wrap at the end.

The bars. Each splits tokens into distinct forms and repeated slots (tokens minus forms). The first is the model's scoring window. Source bars use full eligible pools with different sizes; their shares are not length-controlled MATTR. Counts beside each bar show the denominator. Source forms use Timm's initial-gallows normalization; emitted text is scored by spelling.

Source history. Counts are saved availability at the start of the current model line, excluding unfinished text. The archive stores previous paragraph-opening lines except the seed; it stays stored while closed on body lines. The gold graph strip shows local source tokens. Native access resets before the last line of each page.

Continuous reading. The reader follows the word across pages. Scroll to browse; “Follow word” returns to playback. “Manuscript text” shows the aligned observed window. Source bars and the source-pair explanation still describe the model. Arrow keys step; Space plays or pauses. Only nearby text is rendered, and source words are not rebuilt during playback.
